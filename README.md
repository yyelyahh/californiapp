# California

Webapp que monitora estoque, podendo realizar entrada de estoque, saida/venda, com relatorios de preços de compra, preço de venda, gastos com despesas e dinheiro investido por terceiros permitindo com que planeje o pagamento mensal de dividendos para os investidores e tome decisões de compras por meio de insights simples e rápidos.

This project was built with [Lovable](https://lovable.dev).
